## 功能截图

中英文截图分别位于 `screenshots/zh-CN` 和 `screenshots/en`，尺寸均为 800 × 600 px。

建议上传顺序：

1. `02-downloading.png`：展示逐项进度和总体进度。
2. `03-completed.png`：展示多素材 Carousel 完成状态。
3. `04-settings.png`：展示下载引擎、浅色主题和插件版本。
4. `01-input.png`：展示等待输入链接的主界面。

截图使用匿名示例名称，不包含真实账号、帖子内容或第三方平台标志。

Eagle 官方说明未限定封面图和功能截图的固定像素尺寸。若提交页面提示其他尺寸或比例，应以提交页面的即时要求为准。
