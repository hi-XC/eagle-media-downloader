# Windows 实机测试清单

本清单用于确认 Media Downloader `0.2.0` 能否在 Windows 版 Eagle 中公开发布。测试不需要使用终端或输入命令。

## 测试前准备

- 一台 Windows 10 或 Windows 11 电脑，建议使用 x64 处理器。
- Eagle 4.0 或更高版本。
- 一个临时 Eagle 素材库。不要直接使用重要的正式素材库。
- `media-downloader-v0.2.0.eagleplugin` 测试包。
- 至少三个无需登录即可打开的 Instagram 链接：单张图片或单个视频、纯图片 Carousel、图片和视频混合 Carousel。

测试期间，不要关闭 Windows Defender，不要输入 Instagram 账号，不要导入浏览器 Cookie。如果系统要求关闭安全功能、输入账号或提供 Cookie，请停止测试并截图。

## 记录环境

1. 打开 Windows 的「设置 > 系统 > 系统信息」。记录 Windows 版本和「系统类型」。
2. 打开 Eagle 的「关于 Eagle」。记录 Eagle 版本和 build 编号。
3. 记录 Eagle 当前使用的语言和主题。

## 安装插件

1. 将测试包传到 Windows 电脑。
2. 双击 `media-downloader-v0.2.0.eagleplugin`。
3. 按照 Eagle 的提示安装或更新插件。
4. 如果 Eagle 提示安装 FFmpeg 依赖，请允许 Eagle 安装。
5. 在 Eagle 插件列表中确认名称显示为 `Media Downloader`；中文环境应显示为「素材下载助手」。

预期结果：插件成功安装，不要求管理员权限，也不要求关闭 Windows Defender。

## 检查下载引擎

1. 打开插件。
2. 如果插件显示首次设置页面，安装 yt-dlp。
3. 打开右上角的设置页面。
4. 检查 yt-dlp 是否显示版本 `2026.07.04` 和「已是最新版」。
5. 检查 FFmpeg 是否显示「由 Eagle 管理」。
6. 截取设置页面。

如果 yt-dlp 下载失败，请保留页面，不要反复安装。记录错误文字并截图。

## 测试公开帖子

每个测试都先在浏览器中确认链接无需登录即可打开，再粘贴到插件。

| 测试内容 | 检查结果 |
| --- | --- |
| 单张图片或单个视频 | 成功导入 1 项，来源链接正确 |
| 纯图片 Carousel | 导入数量与帖子数量一致，顺序一致 |
| 图片和视频混合 Carousel | 图片和视频数量一致，顺序一致，视频可以播放 |

对每个链接执行以下步骤：

1. 记录帖子中可见的图片和视频总数。
2. 将链接粘贴到插件并开始下载。
3. 检查解析期间是否持续显示已等待时间。
4. 检查下载期间是否显示总体进度和当前项目进度。
5. 等待任务完成。
6. 检查 Eagle 中新增素材的数量、类型和顺序。
7. 打开一个导入项目，确认来源链接可以返回原帖。
8. 确认插件没有自动添加 Instagram 标签。
9. 截取插件完成状态和 Eagle 中的导入结果。

## 检查界面功能

1. 只完成一条下载记录，确认列表上方出现「清除」。
2. 点击图钉按钮，确认切换到其他窗口后插件仍保持置顶。
3. 再次点击图钉按钮，确认可以取消置顶。
4. 关闭并重新打开插件，确认没有崩溃或空白窗口。
5. 分别切换 Eagle 浅色和深色主题，确认文字、按钮和进度条清晰可见。
6. 检查下载速率文字，确认没有乱码。

## 失败和恢复

出现以下任一情况时，先停止测试并记录，不要自行修改系统安全设置：

- Windows Defender 阻止或隔离 yt-dlp；
- Eagle 或插件崩溃；
- 插件窗口长时间无响应；
- 要求输入平台账号、密码或 Cookie；
- 素材数量、类型或顺序不一致；
- 视频导入后无法播放；
- 文件名、下载速率或错误提示出现乱码。

任务失败时，可点击「复制错误」并保存文字。原始帖子链接无需发给维护者；可以只提供帖子类型、素材数量、截图和错误文字。
